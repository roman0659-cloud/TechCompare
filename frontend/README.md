# TechCompare Frontend

React + Vite frontend for the supplied Spring Boot API.

Backend: http://localhost:8080
Frontend: http://localhost:5173

Run:
```bash
npm install
npm run dev
```

The UI keeps categories isolated, supports up to three devices, calls the supplied search/details/compare/AI endpoints, renders a purpose-based hexagonal radar chart, and provides an AI overview area. The Gemini key remains on the backend.
